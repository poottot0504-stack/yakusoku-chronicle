# Lv300特技魔法・10枠セット 設計と実装計画
全20ジョブにLv120/150/200/250/300の5技を追加（計100技）。Lv100以下の最大火力より新しい攻撃技の合計倍率を高くする。回復・蘇生・補助は既存の同系統の技を上回る量/倍率/対象範囲とする。新MPは55〜160、強力な技ほど消費が増える。
キャラ別battleSkillLoadoutsをジョブID→技ID配列で保存し最大10件。現在ジョブの習得済み技だけをセット可能。0件も可。未設定の旧セーブはLv100までの従来習得技から最大10件を初期選択。新技は習得時に枠へ自動追加せずユーザーが選択。転職先が未設定ならそのジョブの従来習得技を初期選択。設定はキャラ・ジョブごとに保持。新規プレイヤーは従来技の習得時に空き枠へ自動追加（旧進行の操作負担維持）し、ユーザーが手動設定したら自動追加を停止。
パーティカードごとに「特技・魔法リスト」ボタン。ジョブ画面からも開ける。リストはセット数、技名、必要Lv、消費MP、対象、威力/効果/持続の説明、習得状況、セット/解除ボタンを表示。未習得・11個目・他ジョブを拒否。バトル中の編集は不可。変更は即保存、キャラ切替対応。
通常戦闘・レイドともgetBattleSkillsをセット済みリストとし、説明文を両方に表示。レイドで異なる効果は説明を区別。既存セーブと不正対策用ファイル・API契約は維持。

## Tasks
1. 既存習得ロジックをgetLearnedBattleSkillsへ分離、10枠セット検証と保存移行をテスト後実装。
2. 新技100種と説明を追加、各ジョブ習得境界・火力・MP・対象効果をテスト。
3. 各キャラボタン・セット画面・両バトル説明を接続、スマホ画面・設定保存・転職・レイド反映を検証。
4. 最新不正対策との差分確認、全JS構文検証、2000ファイル未満の完全ZIPを作成。
